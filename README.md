# 🧠 CogniStream: Developer Flow-State & Cognitive Load Analytics

## 📌 Project Overview

**CogniStream** is a data analytics project designed to analyze developers' workflow patterns, flow states, and cognitive load during coding activities. The project aims to identify productivity trends, interruptions, workload patterns, and factors that influence developer performance.

By analyzing developer activity data and relevant performance indicators, CogniStream provides meaningful insights through data visualization and an interactive dashboard.

## 🎯 Objectives

- Analyze developer activity and work patterns.
- Identify flow-state patterns and productivity trends.
- Measure cognitive load using available activity indicators.
- Study the impact of interruptions and task switching.
- Visualize insights through interactive dashboards.
- Support data-driven recommendations for improving developer workflows.

## 🛠️ Technologies Used

- **Programming:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn, Plotly
- **Dashboard:** Streamlit
- **Development & Collaboration:** Git and GitHub

## 📊 Key Features

1. **Developer Activity Analysis** – Explore coding sessions, work duration, and activity patterns.
2. **Flow-State Analysis** – Identify periods of sustained activity using available workflow indicators.
3. **Cognitive Load Analysis** – Examine workload-related indicators, interruptions, and task-switching patterns.
4. **Productivity Insights** – Compare work sessions and discover trends.
5. **Interactive Dashboard** – Present important metrics and visualizations in one place.
6. **Data-Driven Recommendations** – Suggest workflow improvements based on the observed data.

## 🚀 Expected Outcome

CogniStream aims to deliver a data analytics solution that transforms developer workflow data into understandable insights about flow state, cognitive workload, interruptions, and productivity. The dashboard will help communicate these findings through clear metrics and visualizations.

## ⚠️ Note

Flow state and cognitive load are analytical estimates based on the available data and selected indicators. They should not be treated as direct measurements of a developer's mental state.
