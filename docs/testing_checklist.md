CogniStream Testing Checklist

Objective

Prepare test cases for the data processing, analytics, and dashboard workflow.

Test Cases

Data Validation

- Check that the dataset loads correctly.
- Verify missing and duplicate records.
- Confirm that timestamps are valid.

Feature Validation

- Verify session duration calculations.
- Check task switching frequency.
- Validate coding activity percentages.

Flow-State Logic

- Test high, moderate, and low focus examples.
- Check how missing values are handled.
- Verify that results follow the documented rules.

Dashboard Validation

- Confirm that metric labels are correct.
- Check that charts use the correct data.
- Verify behavior when the dataset is empty.

Expected Output

A testing checklist for the initial CogniStream prototype.

Reporting

Document each test case, expected result, actual result, and status.
