# Flow-State Estimation Algorithm

## Objective
Define a preliminary method to estimate developer focus using activity indicators.

## Input Features
- Focus session duration
- Task switching frequency
- Break frequency
- Coding activity consistency

## Proposed Logic
1. Read the preprocessed activity data.
2. Calculate the selected activity indicators.
3. Compare indicators against documented thresholds.
4. Assign a preliminary focus category.
5. Store the result for dashboard visualization.

## Preliminary Categories
- High Focus
- Moderate Focus
- Low Focus

## Expected Output
A documented algorithm for estimating focus from activity patterns.

## Limitation
These categories represent heuristic estimates, not confirmed psychological flow states. Validate thresholds before drawing conclusions.
