Data Analysis Plan

1. Introduction

This document describes the analysis approach for CogniStream, a project designed to study developer flow state and cognitive load through activity patterns.

2. Objectives

- Understand developer activity distribution.
- Identify uninterrupted focus periods.
- Analyze context switching frequency.
- Study indicators associated with cognitive load.
- Present useful insights through dashboard visualizations.

3. Data Inputs

The analysis will use the sample developer activity dataset and the activity categories documented by the team.

4. Key Metrics

- Coding duration
- Debugging duration
- Break duration
- Meeting duration
- Number of context switches
- Focus score
- Cognitive-load indicator

5. Analysis Methods

Activity Distribution

Compare the time spent on different types of developer activities.

Focus Analysis

Identify longer uninterrupted coding periods and compare them with interrupted periods.

Context Switching Analysis

Examine how frequently developers move between activities and explore its relationship with focus scores.

Cognitive Load Analysis

Explore patterns in the available cognitive-load indicators alongside debugging activity, context switching, and focus scores.

6. Visualization Plan

- Bar chart for activity distribution.
- Line chart for activity trends over time, when timestamps are available.
- Bar chart for context switching comparisons.
- Scatter plot to explore relationships between focus scores and cognitive-load indicators.

7. Expected Outcomes

The analysis should help identify workflow patterns, interruptions, and possible indicators of high cognitive load.

8. Limitations

Sample data is illustrative and cannot establish real-world conclusions. Focus scores and cognitive-load indicators should not be treated as medical measurements or definitive judgments of developer performance.

9. Conclusion

This analysis plan provides a structured approach for turning developer activity data into useful insights for the CogniStream dashboard.
