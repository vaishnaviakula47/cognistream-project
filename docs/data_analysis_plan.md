Data Analysis Plan

Objective

Prepare developer activity data for analysis.

Steps

1. Load the sample activity dataset.
2. Check for missing values.
3. Remove duplicate records.
4. Convert timestamps into a consistent format.
5. Group activities by developer and time period.
6. Calculate activity duration and interruption counts.
7. Prepare a clean dataset for visualization.

Expected Output

A documented workflow for cleaning and analyzing developer activity data.
