# Flow State Detection Rules

## Objective
Define rules to identify possible developer flow states from activity data.

## Indicators
- Consistent coding activity
- Fewer interruptions
- Longer uninterrupted work sessions
- Balanced task switching
- Stable activity patterns

## Basic Classification
- High Flow: Sustained activity with few interruptions.
- Moderate Flow: Regular activity with occasional interruptions.
- Low Flow: Frequent interruptions or highly fragmented activity.

## Important Note
These are preliminary rule-based indicators, not a direct measurement of a developer's mental state. Thresholds should be validated using data.

## Expected Output
A documented set of rules for future flow-state analysis.
