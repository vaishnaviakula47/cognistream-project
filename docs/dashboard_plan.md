# CogniStream Dashboard Plan

## Introduction

The CogniStream dashboard will display developer activity analytics in a simple and understandable format.

## Dashboard Objectives

- Display coding activity summaries.
- Visualize focus-session duration.
- Show interruption frequency.
- Analyze task-switching patterns.
- Present estimated workload indicators.

## Dashboard Components

### 1. Summary Cards

Display total active minutes, number of sessions, recorded interruptions, and task switches.

### 2. Focus Session Chart

Show the duration of coding sessions across selected dates.

### 3. Interruption Chart

Display recorded interruptions by date or session.

### 4. Task Switching Chart

Visualize task changes during coding sessions.

### 5. Filters

Allow users to select a date range and, where authorized, a developer identifier.

### 6. Data Table

Display the activity records used for analysis.

### 7. Privacy Notice

Explain how activity data is used and clarify that workload indicators are estimates.

## Expected Outcome

The dashboard will help users explore developer activity patterns through charts, summary cards, and filters.

## Future Improvements

Future versions may include additional charts, export options, and validated measures of perceived workload.
