Dashboard Metrics Design

Objective

Define the metrics displayed in the CogniStream dashboard.

Proposed Metrics

1. Focus Session Duration
2. Task Switching Frequency
3. Break Frequency
4. Coding Activity Trend
5. Flow-State Estimate
6. Cognitive-Load Indicator

Visualization Plan

- KPI cards for summary metrics
- Line chart for activity over time
- Bar chart for task switching
- Timeline for focus sessions
- Indicator cards for estimated flow state and cognitive load

Expected Output

A dashboard metrics specification that supports future implementation.

Important

Flow state and cognitive load are estimates based on selected indicators, not definitive measurements of a person's mental state.
