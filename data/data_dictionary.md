Developer Activity Data Dictionary

1. Introduction

This document describes the variables used in the Cognistream project dataset. These variables help analyze developer productivity, flow state, and cognitive load.

2. Dataset Variables

Variable| Description| Unit
Coding Time| Total time spent writing or modifying code| Minutes
Break Time| Time spent taking breaks| Minutes
Context Switches| Number of times a developer switches between tasks| Count
Tasks Completed| Number of tasks completed during a work session| Count
Interruptions| Number of unexpected disturbances during work| Count

3. Purpose of the Variables

- Coding Time helps measure time spent on development activities.
- Break Time helps understand work and rest patterns.
- Context Switches help identify frequent task switching.
- Tasks Completed helps track development progress.
- Interruptions help identify disturbances that may affect concentration.

4. Relationship to Project Goals

These variables can be analyzed together to identify patterns associated with developer focus, possible cognitive overload, and productivity.

5. Conclusion

A clear understanding of the dataset variables supports consistent data analysis and helps prepare the project for future visualization and analytics.
